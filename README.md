# Portofolio Saeful Rizki DS

Website portofolio desain grafis: template VistaCreate yang terjual, brand kit, motion graphic Adobe Stock, dan studi kasus CV. FTB Family Trans.

Situs statis satu halaman (`index.html` + folder `img/`), siap dipakai di GitHub Pages.

## Mengaktifkan GitHub Pages

1. Buka repo ini di github.com, lalu masuk ke **Settings → Pages**.
2. Di **Build and deployment**, pilih **Source: Deploy from a branch**.
3. Pilih branch **main** dan folder **/ (root)**, lalu klik **Save**.
4. Tunggu 1–2 menit. Alamat situs muncul di bagian atas halaman Pages.

## Mengganti karya

- Gambar ada di folder `img/`.
- Daftar karya ada di bagian `<script>` dalam `index.html` (array `W` untuk template, `K` untuk brand kit, `AN` untuk motion, `CS` untuk studi kasus, `O` untuk proyek lain).
